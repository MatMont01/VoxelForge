# 🎯 Voxel Forge - Fan Page

Página web profesional para **Voxel Forge**, empresa especializada en servicios de impresión 3D en Santa Cruz de la Sierra, Bolivia.

## 🚀 Tecnologías Utilizadas

- **React 19** - Framework principal
- **TypeScript** - Tipado estático
- **Vite** - Build tool y dev server
- **Tailwind CSS** - Framework de estilos
- **GSAP** - Animaciones avanzadas
- **React Router DOM** - Navegación
- **Lucide React** - Iconografía

## ✨ Características

### 🎨 Diseño Moderno

- Paleta de colores corporativa (#ea9216, #eeeeee, #3a4750, #313841)
- Diseño responsive para todos los dispositivos
- Modo oscuro/claro con transiciones suaves
- Animaciones fluidas con GSAP

### 📱 Funcionalidades Principales

- **Hero Section** con animaciones de entrada
- **Servicios** detallados con precios
- **Equipo** - Información de impresora Bambu Lab P1S
- **Portafolio** con carrusel automático e interactivo
- **Historia** de la empresa desde 2022
- **Contacto** con formulario funcional y WhatsApp

### 🖨️ Servicios Destacados

- Impresión 3D a pedido
- Diseños personalizados
- Prototipos rápidos
- Envíos a todo Bolivia

## 🛠️ Instalación y Desarrollo

```bash
# Clonar el repositorio
git clone [url-del-repo]

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Preview del build
npm run preview
```

## 📁 Estructura del Proyecto

```
src/
├── components/           # Componentes reutilizables
│   ├── layout/          # Header, Footer
│   ├── sections/        # Secciones principales
│   └── ui/              # Componentes UI básicos
├── constants/           # Datos y configuraciones
├── hooks/               # Hooks personalizados
├── pages/               # Páginas principales
├── types/               # Definiciones de tipos
├── utils/               # Utilidades y helpers
└── assets/              # Recursos estáticos
```

## 🎯 Componentes Principales

### Secciones
